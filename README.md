# Hospital-Analytics-Dashboard-
Hospital Analytics Dashboard

📊 Project Overview

An interactive Hospital Analytics Dashboard developed to analyze hospital data and provide meaningful insights into patients, doctors, appointments, payments, and medical records.

🛠️ Tools & Technologies

* SQL
* Microsoft Excel
* Power BI
* Power Query

📌 Dashboard Sections

* Overview
* Patients
* Doctors
* Appointments
* Payments
* Medical Records

🎯 Project Objectives

* Analyze hospital performance
* Track key KPIs
* Identify trends and patterns
* Create interactive data visualizations
* Support data-driven decision making



👥 Team Project

This project was developed as a team project, with collaboration on data preparation, analysis, SQL queries, and Power BI dashboard development
